com.phasmidsoftware.lascala.IncrementableSequential
case class IncrementableSequential[T](t: T, isSnapshot: Boolean = ..., by: String = ...)(using evidence$1: Incrementable[T]) extends OrderedSequential[IncrementableSequential[T]]

This is a simple implementation of the Sequential trait which does not allow for sub-versions.

Type parameters

T

the underlying type of this Sequential: it is defined that there exist an implicit value of Incrementable[T] available -- in practice, this typically means an integer of some sort, as String or a LocalDate.

Value parameters

by

the unit of the increment

isSnapshot

(defaults to false) true if this is a snapshot

t

the value of this IncrementalSequential
